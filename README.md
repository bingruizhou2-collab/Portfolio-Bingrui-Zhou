# Bingrui (Ryan) Zhou — Personal Portfolio

A static, responsive portfolio for a course assignment. It includes a one-sentence professional statement, three organized skills groups, and three project summaries with working internal case-study links.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `ryan-zhou-portfolio` (or another name).
2. Upload the contents of this folder to the repository root, including `index.html`, `styles.css`, and the `projects` folder. Do not upload the containing `portfolio` folder as the only root item.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)` and save.
4. Wait for GitHub Pages to provide a live URL, typically `https://YOUR-USERNAME.github.io/ryan-zhou-portfolio/`.
5. Open the live URL in a private window and follow all three project links. Submit both the public repository URL and the live website URL.

## Before publishing

- You can add a verified email, LinkedIn profile, or GitHub profile later if you want employers to contact you directly.
- If you want to share the original music site, add its verified URL on the music project page.
- The portfolio does not publish class assignment files or unverified project claims.

No build process or dependencies are required. Google Fonts is optional; local fallback fonts are provided.
